# E_COMMERCE_ANALYTICS
🛒 E-Commerce Sales Dashboard | Power BI

An interactive E-Commerce Sales Dashboard developed using Microsoft Power BI to analyze sales, profit, transactions, product performance, customer purchasing patterns, and geographical sales distribution.

🎯 Project Objective

The objective of this project is to transform e-commerce transaction data into an interactive dashboard that provides a clear overview of sales performance, profitability, product categories, payment methods, and regional demand.

📊 Key KPIs
Total Sales: 85,691.12
Total Profit: 13,766.64
Total Transactions: 28
Monthly Sales Analysis
📈 Dashboard Analysis

The dashboard includes:

Total Quantity Sold by State
Total Sales by City
Product-wise Sales Performance
Sales by Product Category
Transaction Type Analysis — Card & COD
Monthly Sales Reporting
Profit & Sales KPIs
Interactive filters and slicers
🛠️ Tools & Techniques
Microsoft Power BI
Power Query for data cleaning and transformation
Data Modeling
DAX
KPI Cards
Interactive Charts & Slicers
Business Data Analysis
Data Visualization
💡 Key Insights

The dashboard helps identify top-performing products, high-sales cities and states, category-wise contribution, preferred transaction methods, and overall sales and profit performance.

📌 Project Outcome

This project strengthened my practical skills in Power BI, Power Query, DAX, data modeling, KPI creation, and interactive business dashboard development, with a focus on turning raw e-commerce data into actionable business insights.
